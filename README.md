# Добеги до квартиры

Мини-игра для канала KeysToMoscow: раннер про съём квартиры в Москве.
Чистый JavaScript и Canvas, без сборки и без сервера. Открывается как сайт и как Telegram Mini App.

- Сайт: https://artemnekras69-code.github.io/dobegi/
- Mini App: https://t.me/KeysToGameBot/run

## Запуск у себя

Любой статический сервер из папки проекта:

```bash
python3 -m http.server 3470
```

После правок поднимайте номер версии `?v=` у файлов в `index.html`, иначе телефон покажет старое из кеша.

## Что где лежит

| Файл | Что внутри |
| --- | --- |
| `apartments.js` | Квартиры для карточек. Массив можно целиком заменить настоящими объявлениями |
| `js/config.js` | Все числа: скорость, прыжок, сложность, палитра, частота вывесок и знаковых мест (`city`) |
| `js/content.js` | Районы, каталог препятствий, тексты, объявления на стенах |
| `js/ink.js` | «Почерк» игры: неровный контур, сдвиг краски, штриховка, растр, зерно |
| `js/art.js` | Герой (покадровая анимация) и карточка квартиры |
| `js/art-obstacles.js` | Все препятствия |
| `js/brands.js` | Пародийные вывески |
| `js/city-art.js`, `js/city-props.js`, `js/city.js` | Город: силуэты, дома, витрины, дворовые мелочи, слои параллакса |
| `js/game.js`, `js/ui.js`, `js/core.js`, `js/audio.js` | Механика, экраны, хранение рекордов, звук |
| `style.css` | Интерфейс |

## Стиль: московская трафаретная аркада

Картинка собрана как дешёвая двухкрасочная печать: плоские пятна, рубленые формы, краска чуть съехала с контура.
Правила, по которым нарисовано всё — от героя до кнопок:

1. **Иерархия контура.** Герой — сплошной чёрный силуэт с бумажным ободком. Препятствия — чёрный контур с нажимом.
   Фон — без чёрного вообще, только тон. Фон никогда не спорит с тем, что на дороге.
2. **Палитра ограничена** (`CONFIG.colors`): бумага, чёрный, асфальт, бетон, два серых, приглушённый зелёный, кирпич, бордо,
   крем, жёлтый, голубой. Лайм и красный — только акцент: карточка, вывеска, опасность, рекорд.
3. **Никаких градиентов, скруглений, бликов и мягких теней.** Тень — плоский параллелограмм. Углы рубленые.
4. **Форма важнее деталей.** Предмет должен узнаваться силуэтом в 30 пикселей. Лишняя мелочь убирается.
5. **Анимация покадровая**, без плавной интерполяции: бег 8 кадров, прыжок из трёх поз, короткое приземление, удар.
6. **Один шрифт** — Sofia Sans (Extra Condensed 900 для заголовков, Condensed для текста).
7. **Вывески — пародии** на знакомые сети: у каждой своя форма, цвет и шутка, но встречаются редко — основной фон
   района составляет обычная застройка.
8. **Плохая квартира не красная.** Карточки одинаковые, отличать их нужно по цифрам.

Всё рисуется через `K.ink` (`poly`, `box`, `disc`, `line`, `hatch`, `dots`, `shadow`, `text`) — новые предметы
делайте теми же вызовами, тогда они попадут в стиль автоматически.
